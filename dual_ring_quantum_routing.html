The dual ring: nine supernodes around the command center

Every supernode sits on two counter-rotating QKD rings: a working ring that runs clockwise and a protection ring that runs counter-clockwise. Supernodes 3 and 7 are the gateways to the command center. Pick a source, then tap a span (click it on the ring or use the buttons): the router runs Dijkstra over the spans that still give key and picks the best path. If no quantum path is left, that traffic falls back to a post-quantum (ML-KEM-768) tunnel.

See it in 3D: open the dual ring in the live grid. There each span is one QKD fiber pair carrying both rings in one corridor, with 8.5 km spans and 6 km command-center links, the same as this page.
