Teleport a qubit across the grid

Alice and Bob share an entangled pair built over real fibers. Alice measures two qubits and sends Bob two classical bits over the network; Bob fixes his qubit. Nothing travels faster than the fiber, and the swapping nodes on the way never hold a key. This is a roadmap capability, not part of the live grid.

Computed here: a 3-qubit state-vector simulation, with each fiber's measured-style error rate applied to Bob's half of the pair as bit and phase flips. Errors compose along the route as (1 − 2Q) = Π(1 − 2Qᵢ); a pair is usable under 11%. Notebook 3 in this repo has the same circuit in Qiskit.

Catch the eavesdropper (BB84)

The protocol running on every green fiber of the live grid. Alice sends photons in random bases; Bob measures in random bases; they keep the rounds where the bases match. A spy who measures and resends must guess the basis, and every wrong guess shows up as errors.

Grover: how fast can a key be guessed?

Grover's search finds one key among N in about √N tries instead of N. For AES-128 that is like halving the key length, which is why new equipment should use AES-256. Below: the exact success probability, and what real machines did.

Random guessing: 25% (N = 4), 12.5% (N = 8). The right key stays the most common answer on real hardware, but the peak shrinks fast as circuits grow. Job IDs and details: WRITEUP_step2.md. Also on Rigetti: Shor on 15 (hand-reduced circuit) put 65% of shots on the four ideal outcomes, against 25% for noise.

Real code behind the grid

When the project runs with python3 grid-twin/start.py, every QKD fiber in the live grid can be re-run as real quantum programs. These are excerpts of the code that runs.

@cudaq.kernel
def bb84_round(bit: int, basis: int, eve_on: int, eve_basis: int, flip: int):
    q = cudaq.qubit()
    anc = cudaq.qubit()
    if bit == 1: x(q)
    if basis == 1: h(q)
    if eve_on == 1:              # Eve measures in her basis:
        if eve_basis == 1: h(q)  # copy into an ancilla nobody reads
        x.ctrl(q, anc)
        if eve_basis == 1: h(q)

What is next, and what is not built

Next

GPU: qBraid's GPU simulators (35-qubit state vector, 500-qubit tensor network) to re-check every fiber at once and run whole teleportation routes as one circuit. Hardware: notebook 3's teleportation on a real QPU. Cost: a sourced cost model; we found no published QKD prices.

Not built

No AI assistant, GraphQL API or Next.js app exists in this project; they were ideas on our technology list (ranked here). No breaker is tripped by teleportation: teleportation needs a classical message, so it is never faster than the fiber.

Satellites

Likely to be taken out unless we find a quantum application only a satellite can serve. Chattanooga's links are all under 23 km, well inside fiber QKD's reach.
